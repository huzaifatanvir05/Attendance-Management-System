# Attendance Management System

A console-based Attendance Management System developed in C++. The project is designed to manage student attendance records through a structured and menu-driven interface while demonstrating fundamental programming concepts and organized data handling.

---

## Overview

The Attendance Management System provides a simple interface for managing and tracking student attendance. It enables users to maintain records efficiently and interact with the system through a structured menu-driven workflow.

---

## Features

- Add student records
- Mark student attendance
- View attendance information
- Structured menu-driven interface
- Organized data management
- User-friendly console interaction

---

## Technologies Used

- C++
- Standard Template Library (STL)
- Functions
- Arrays / Vectors
- Strings
- Menu-Driven Programming
